# yfish — CYD 水族箱（繁體中文版）

這是一款適合 iPhone 及電腦瀏覽器使用的虛擬水族箱遊戲，改編自 ESP32 [CYD-Aquarium](https://github.com/littlehohk/CYD-Aquarium)。玩家需要餵養金色小魚、陪牠玩耍，並調節水溫。**小魚存活七天後會變成金色海蛇**，屆時改以小活魚餵食。

## 開始遊玩

- **繁體中文版：** [indexC.html](indexC.html)
- **English version：** [index.html](index.html)

啟用 GitHub Pages 後，中文版可於下列網址直接遊玩：

**https://littlehohk.github.io/yfish/indexC.html**

以 iPhone 的 Brave 或 Safari 開啟即可，毋須安裝應用程式；亦可在電腦瀏覽器中使用。

## 操作方法

- **輕觸水面：** 投下魚糧。小魚長成海蛇後，會改為放出小活魚。
- **在水族箱內滑動：** 與魚兒玩耍，降低無聊指數。魚兒亦可能受驚游開。
- **冷氣：** 開啟降溫；再次點按可關閉。
- **暖水：** 開啟暖水器升溫；再次點按可關閉。冷氣與暖水器不可同時運作。
- **燈光：** 開關照明燈，每次有效切換也計作玩耍；關燈後按當地日出日落調節亮度。
- **設定：** 搜尋城市、更新戶外天氣，或在無法取得天氣資料時手動設定戶外氣溫。
- **魚兒死亡後：** 按住底部「按住兩秒：養新魚」區域兩秒，即可重新開始。

## 飼養規則

| 項目 | 規則 |
| --- | --- |
| 初始狀態 | 飢餓 2.5、無聊 2.5、年齡零 |
| 自然變化 | 飢餓及無聊指數每 20 分鐘增加 0.1 |
| 餵食 | 每吃下一粒魚糧或一條小魚，飢餓指數下降 0.1 |
| 玩耍 | 每次滑動或有效切換燈光，無聊指數下降 0.1 |
| 過度進食 | 飢餓指數**連續一小時低於 0.2**，便會死亡 |
| 飢餓 | 飢餓指數**連續一小時高於 4.7**，便會死亡 |
| 過度興奮 | 無聊指數**低於 0.2**，即時死亡 |
| 極度無聊 | 無聊指數**高於 4.7**，即時死亡 |
| 失溫 | 水溫**連續 30 分鐘低於 14°C**，便會死亡 |
| 高溫 | 水溫**連續 30 分鐘高於 28°C**，便會死亡 |
| 進化 | 存活滿七天後變成金色海蛇 |

**注意：** 指數正好等於 0.2 或 4.7 並不會觸發相關死亡條件。投在魚兒身後的食物要三秒後才會被察覺，未吃掉的食物會沉到底部並消失。

### 水溫變化

水溫的自然目標由戶外氣溫決定：

| 戶外氣溫 | 自然目標水溫 |
| --- | --- |
| 高於 30°C | 戶外氣溫 − 6°C |
| 高於 22°C 至 30°C | 戶外氣溫 − 3°C |
| 16°C 至 22°C | 與戶外氣溫相同 |
| 8°C 至低於 16°C | 戶外氣溫 + 3°C |
| 低於 8°C | 戶外氣溫 + 6°C |

冷氣每 30 分鐘降溫 1°C；暖水器每 30 分鐘升溫 1.5°C；兩者均關閉後，水溫每五分鐘以 0.2°C 的速度接近自然目標水溫。水溫指示顏色由白色、淺黃色、淺藍色、淺粉紅色至紅色，表示由過冷至過熱。

## 天氣、晝夜與存檔

遊戲預設城市為**香港沙田**，可在設定中改選其他城市。連線時會透過 [Open-Meteo](https://open-meteo.com/) 取得天氣；亦可手動設定戶外氣溫。自然光暗依據所選城市的地理位置與太陽位置推算。

遊戲採用瀏覽器 **localStorage** 自動保存進度，並按現實時間計算魚兒的年齡和需求。即使關閉頁面，時間仍會流逝，因此再次開啟時可能發現魚兒已因照顧不足而死亡。

請留意：

- 英文版與中文版使用**相同的本機存檔識別碼**；從同一網站及同一瀏覽器開啟時，會共用遊戲進度。
- 不同瀏覽器、裝置或網站來源的存檔不會自動同步。
- 清除網站資料或使用私密瀏覽可能導致進度遺失。
- 下載為本機 HTML 與透過 GitHub Pages 開啟，可能使用不同的儲存空間。

## GitHub Pages 設定

在 GitHub 儲存庫的 **Settings → Pages**，選擇 **Deploy from a branch**，並設定 **main** 分支、**/(root)** 資料夾，然後按 **Save**。

部署完成後，可開啟：

- 繁體中文版：https://littlehohk.github.io/yfish/indexC.html
- 英文版：https://littlehohk.github.io/yfish/
